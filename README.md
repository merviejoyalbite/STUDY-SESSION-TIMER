# Study Session Timer

A Study Session Timer built using:

- Vanilla JavaScript
- Node.js
- Express.js
- MySQL
- MVC Architecture

---

## Features

- User Registration
- User Login Authentication
- Study Session CRUD
- Animated Pomodoro Timer
- Responsive Dashboard
- Session Tracking
- Sidebar Session Manager

---

## Technologies Used

Frontend:
- HTML
- CSS
- Vanilla JavaScript

Backend:
- Node.js
- Express.js
- MySQL
- Express Session
